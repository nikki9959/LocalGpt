LOCALGPT FIXED FINAL V8

Run:
1. Double-click START.bat
2. Upload one or more files into a chat.
3. Ask any question.

Supported: PDF, DOCX, PPTX, XLSX, TXT, MD, CSV, JSON, PNG, JPG, JPEG, WEBP, BMP, GIF.

Behavior:
- Every chat has its own messages and file list.
- Files from one chat are never used by another chat.
- Multiple files can be attached to one chat.
- You can ask multiple questions in the same chat.
- File questions use the attached files when relevant.
- If a question is unrelated to the attached files, LocalGPT can answer it normally.
- PDF text keeps page markers so page-specific questions are easier to answer.
- Images use local OCR when available. A local Ollama vision model is needed for questions requiring visual understanding beyond readable text.
- Ollama stays local on your computer.
- The app keeps the Ollama model warm for faster consecutive questions.

No cloud service is required by LocalGPT.
