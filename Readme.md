# LocalGPT – Private Local Document Intelligence

LocalGPT is a private, locally running AI assistant that lets users upload documents and images, then ask questions about them using a local Ollama AI model.

## Features

- Upload PDF, DOCX, PPTX, XLSX, TXT, CSV and JSON files
- Upload images and extract text using local OCR
- Ask multiple questions in the same chat
- Upload multiple files in one chat
- Separate chats keep their files and conversations isolated
- Summarize documents and answer questions from specific pages
- Ask general questions even without an uploaded file
- Runs with Ollama locally
- Designed for private, local document processing
- Keeps the local AI model available for faster consecutive questions
- Simple web-based interface with a ChatGPT-style experience

## How It Works

1. Start LocalGPT using `START.bat`.
2. Upload a document or image.
3. Ask a question about the uploaded content.
4. LocalGPT processes the relevant content locally.
5. Ollama generates the answer.
6. Each chat maintains its own files and conversation history.

## Privacy

Your uploaded documents, images, extracted text and chat data are intended to remain on your local computer. No cloud AI API is required.

## Requirements

- Windows
- Python 3
- Ollama
- A locally installed Ollama model

LocalGPT is designed as a lightweight private alternative for interacting with personal documents using local AI.
